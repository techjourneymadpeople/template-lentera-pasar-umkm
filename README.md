# 🏮 Lentera Pasar — Template Website Etalase Publik UMKM

Repository ini berisi kumpulan kode sumber **Template Website Etalase Publik (Multi-Page)** siap pakai yang dirancang khusus untuk pelaku UMKM di ekosistem platform **Lentera Pasar**.

Setiap template dibuat dengan standar **UI/UX Modern, Mobile-First, Fast-Loading, dan Conversion-Focused**, terintegrasi langsung dengan fitur pemesanan instan WhatsApp (*Direct WhatsApp Booking*) serta siap dihubungkan ke Admin Panel & Meta Ads Engine Lentera Pasar.

---

## 🌟 Fitur Utama Setiap Template

- **🎨 Multi-Design Archetype (Non-Bento Grid)**: Desain khusus yang disesuaikan dengan psikologi visual tiap niche industri (Bold Pop, Dark Industrial, Clean Minimalist, Warm Artisan, Soft Pastel).
- **📱 100% Mobile-Responsive**: Tampilan responsif sempurna di semua perangkat (Smartphone, Tablet, Laptop, Desktop).
- **⚡ Direct WhatsApp Checkout & Order Compiler**: Form dan customizer pesanan secara otomatis menyusun pesan WhatsApp rapi ke Admin / Customer Service.
- **🏷️ Interactive Product Customizer**: Pilihan varian rasa, level pedas, ukuran kemasan, porsi, kalkulator kuantitas/harga otomatis, serta link toko marketplace (Shopee, Tokopedia, TikTok Shop).
- **🔍 Live Search & Category Filtering**: Filter instan tanpa reload halaman dan pengurutan harga termurah/tertinggi.
- **🏮 Sticky Demo & Sales Bar**: Komponen promosi terpadu Lentera Pasar yang menempel di bagian bawah layar.
- **🚀 SEO-Ready & Semantic HTML5**: Struktur heading hierarchy yang rapi, meta description, Open Graph ready, dan performa tinggi.

## 📑 Struktur Halaman Standar (7 File per Template)

Setiap template sub-bidang memiliki 7 file HTML mandiri:

1. `index.html` — **Beranda Utama**: Hero banner, Value proposition, Highlight produk terlaris, Peta rasa/kategori, dan Testimoni pelanggan.
2. `katalog.html` — **Katalog Produk**: Daftar seluruh menu/produk dengan live search, filter kategori pills, dan sorting harga.
3. `detail.html` — **Detail Produk**: Galeri foto interaktif, customizer varian/porsi/level, quantity stepper, dan tombol WhatsApp compiler.
4. `tentang.html` — **Profil & Cerita Brand**: Kisah dapur, standar higienis, sertifikasi Halal / P-IRT, dan peluang reseller/agen.
5. `kontak.html` — **Pusat Pengiriman & Toko**: Info outlet, jam operasional CS, jangkauan ekspedisi, FAQ, dan form pemesanan instan.
6. `artikel.html` — **Tips & Edukasi Niche**: Daftar artikel panduan penyajian, tips penyimpanan, dan rekomendasi menu.
7. `baca-artikel.html` — **Halaman Baca Artikel**: Konten lengkap artikel edukasi dengan box CTA order WhatsApp di tengah artikel.

## 🚀 Cara Menjalankan Template Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/techjourneymadpeople/template-lentera-pasar-umkm.git
   cd template-lentera-pasar-umkm
   ```

2. **Jalankan via Live Server (VS Code / Browser)**:
   - Buka folder template pilihan Anda (misal `fnb-ricebowl-pop/index.html` atau `fnb-meat-butcher/index.html`).
   - Klik kanan dan pilih **"Open with Live Server"** atau buka file `.html` langsung di browser Anda.
