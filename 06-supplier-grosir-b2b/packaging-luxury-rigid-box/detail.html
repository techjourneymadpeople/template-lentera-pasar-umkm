Cara Menentukan Ukuran Inset Busa Sesuai Botol Klien

Langkah 1

Ukur Diameter & Tinggi

Ukur dimensi luar botol parfum/serum (termasuk tutup pipet atau pump spray) dengan jangka sorong presisi.

Langkah 2

Toleransi Celah 1.5mm

Mesin laser CNC kami akan memberikan celah 1.5mm di sekeliling botol agar botol mudah diambil namun tidak goyang.

Langkah 3

Finger Notch Celah Jari

Tambahkan coakan setengah lingkaran di sisi botol agar konsumen mudah mencubit dan mengangkat botol dari busa.

Ketentuan File Hot Stamping Foil:

  • Format file Vector: Adobe Illustrator (.AI), CorelDRAW (.CDR), atau PDF Vector.
  • Ketebalan garis minimal untuk foil emas: 0.3 pt (agar plat klise tembaga tajam).
  • Jarak aman teks/logo dari tepi box: minimal 1.5 cm dari garis lipatan.
  • Font wajib di-create outline / convert to curves untuk menghindari missing font.
Layanan 3D Visual Rendering Gratis:
