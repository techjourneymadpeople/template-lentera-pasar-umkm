The Artisanal Hand-Poured Ritual

Dituang Tangan dalam Batch Kecil untuk Kualitas Sempurna.

Kami menolak proses produksi massal pabrik. Setiap jar lilin di studio LUMINA dituangkan dengan tangan dalam kelompok kecil (*small-batch*) pada suhu leleh kedelai 55°C yang tepat, memastikan minyak esensial terikat sempurna dengan molekul soy wax tanpa teroksidasi.

Sumbu kayu kami dipotong manual dari kayu maple bersertifikasi lestari yang menghasilkan suara gemeretak api (*wood crackle sound*) menyerupai api unggun mini di samping tempat tidur Anda.

Zero Petroleum Paraffin: Tidak menimbulkan noda asap hitam jelaga di dinding kamar.
